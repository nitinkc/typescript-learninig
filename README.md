# TypeScript Learning

A standalone, searchable TypeScript syntax reference for everyday development with React, Angular, Node.js, and framework-independent TypeScript.

## Run locally

```bash
uvx --with mkdocs-material mkdocs serve
# OR
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
mkdocs serve
```

Open the local URL printed by MkDocs. Build the static site with:

```bash
mkdocs build --strict
```
